SHAILVI KUMARI PORTFOLIO WEBSITE
=================================

FILES
- index.html: the full responsive website (HTML + CSS + small JavaScript in one file).
- README.txt: editing and publishing instructions.

HOW TO EDIT
1. Open index.html in a text editor (VS Code is recommended; Notepad also works).
2. Search for placeholder wording such as "Add a screenshot", "YOUR_EMAIL@example.com", and "Add your profile URL".
3. Replace the text and links with your own content.
4. To add a screenshot, put the image file in the same folder and replace a placeholder <div class="placeholder">...</div> with:
   <img src="your-image.png" alt="Description of your dashboard" style="width:100%;height:auto;border-radius:12px">
5. Save index.html and open it in a browser to preview.

PUBLISHING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. shailvi-portfolio.
3. Upload index.html to the repository's root (and any images you add).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the published site link to appear in Settings → Pages. It will usually resemble:
   https://shailvikumari.github.io/shailvi-portfolio/
7. To update the website later, edit/upload index.html and images in the same repository. GitHub Pages republishes the changes.
